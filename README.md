# EdgeEver 日历插件 (edgeever-rili)

为 EdgeEver 笔记软件添加日历功能的插件，支持公历和农历显示。

## 功能特性

### 📅 日历视图
- 显示当月月历，包含公历和农历日期
- 每个日期显示当天有多少篇笔记（热力图）
- 支持年份和月份切换查看历史月份
- 显示当月的笔记列表，最新的在最上面

### 🎂 生日联动（配合人际关系插件）
- 自动读取带「人际」标签的联系人笔记中的「生日：YYYY-MM-DD」字段
- 日历对应日期显示生日标记（🎂 姓名 + 当年满几岁），点击直达联系人笔记
- 面板下方「本月生日」列表按日期排序，快速查看本月谁过生日
- 2月29日生日的联系人在平年显示于 2月28日
- 联系人标签可在插件设置中修改（默认「人际」，与人际关系插件一致）

### ⌨️ 快捷键支持
- `Ctrl + ;`：插入当前日期
- `Ctrl + Shift + ;`：插入当前时间（包含日期）

### 🌙 农历支持
- 完整的农历数据（1900-2100年）
- 显示农历月份和日期
- 支持闰月显示

### 🎨 热力图
- 用不同颜色深浅表示每天笔记数量
- 直观显示写作活跃度

## 安装方法

1. 将插件文件复制到 EdgeEver 的插件目录
2. 重启 EdgeEver
3. 在插件管理中启用 "EdgeEver 日历" 插件

## 使用方法

### 打开日历面板
1. 通过命令面板搜索 "打开日历面板"
2. 或通过插件管理中的日历面板入口

### 快捷键使用
1. 在编辑笔记时，使用 `Ctrl + ;` 插入当前日期
2. 使用 `Ctrl + Shift + ;` 插入当前时间

### 日历导航
- 点击 "上月" / "下月" 按钮切换月份
- 点击 "今天" 返回当前月份
- 使用顶部下拉菜单选择年份和月份

### 查看笔记
- 日历中带有颜色点的日期表示有笔记
- 点击日期下方的笔记列表可打开对应笔记
- 笔记按日期分组显示，最新的在最上面

## 配置选项

在插件设置中可以调整以下选项：

- **日历标签**：带有此标签的笔记会在日历中显示（默认："日历"）
- **日期格式**：插入日期的格式（默认："YYYY-MM-DD"）
- **时间格式**：插入时间的格式（默认："YYYY-MM-DD HH:mm"）

## 支持的日期格式

### 日期格式占位符
- `YYYY`：四位年份（如：2024）
- `MM`：两位月份（如：01-12）
- `DD`：两位日期（如：01-31）

### 时间格式占位符
- `HH`：24小时制小时（如：00-23）
- `mm`：分钟（如：00-59）

## 示例

### 日期格式
- `YYYY-MM-DD` → 2024-03-15
- `MM/DD/DD` → 03/15/24
- `DD MM YYYY` → 15 03 2024

### 时间格式
- `YYYY-MM-DD HH:mm` → 2024-03-15 14:30
- `MM/DD/DD HH:mm` → 03/15/24 14:30
- `DD MM YYYY HH:mm` → 15 03 2024 14:30

## 技术细节

### 农历算法
- 基于天文算法计算农历日期
- 支持 1900-2100 年的农历数据
- 包含闰月计算和节气信息

### 热力图颜色
- 无笔记：灰色 (#f0f0f0)
- 少量笔记：浅绿色 (#ebedf0)
- 中等笔记：绿色 (#c6e48b)
- 大量笔记：深绿色 (#239a3b)
